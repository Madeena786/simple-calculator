# **Simple Calculator**



**Description**



This project is a simple calculator developed using Python.



It accepts two numbers and performs:



* Addition
* Subtraction
* Multiplication
* Floor Division
* Division
* Modulus



**Technologies Used**



\- Python



**Features**



\- Performs basic arithmetic operations

\- Uses separate functions for each operation

\- Handles division by zero

\- Displays results clearly



**How to Run**



1\. Install Python.

2\. Download or clone this repository.

3\. Open the project folder.

4\. Run `calculator.py`.



**Example**



**Input:**



20

6



**Output:**

Enter first number: 20

Enter second number: 6
